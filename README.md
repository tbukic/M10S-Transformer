# Minimal10DigitTransformer

A minimal transformer for 10-digit recognition with NVIDIA GPU support

## Stack

- Python 3.13 managed by `uv` + `pyproject.toml`
- Project type: `python_package`
- Docker Compose for local runtime and deploy orchestration
- Devcontainer with Claude Code + configurable tooling

## Devcontainer Base Mode

- `devcontainer_base_type=nvidia_cuda`

If `ubuntu`:
- `.devcontainer/Dockerfile` uses `FROM ubuntu:<ubuntu_version>`.
- No GPU runtime settings are added to compose.

If `nvidia_cuda`:
- `.devcontainer/Dockerfile` uses `FROM nvidia/cuda:<cuda_version>-devel-<cuda_variant>`.
- `.devcontainer/docker-compose.yml` adds:
  - `runtime: nvidia`
  - `NVIDIA_VISIBLE_DEVICES=all`
  - GPU reservation block with `count=all`

## Constants Module

`src/minimal10digittransformer/consts.py` is generated by default and includes:
- `PACKAGE_DIR`
- `PROJECT_ROOT`
- `DATA_DIR` (from `APP_DATA_DIR` env or fallback to `<project>/data`)

## Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

| Variable | Required | Description |
|----------|----------|-------------|
| `WANDB_API_KEY` | Yes | Weights & Biases API key (from https://wandb.ai/authorize) |

The `.env` file is loaded by docker-compose via `env_file` and is git-ignored.

## Quick Start

```bash
cp .env.example .env
# Edit .env and set WANDB_API_KEY
uv sync --extra dev
```

## Run with Docker Compose

```bash
docker compose up --build
```

Stop:

```bash
docker compose down
```

## Version-Driven Service Inclusion

Services are included only when version is provided.
Empty value means service is omitted.

Dev services:
- `dev_postgres_version=`
- `dev_redis_version=`
- `dev_mailhog_version=`

Deploy services:
- `deploy_postgres_version=`
- `deploy_redis_version=`

## Optional Data Mounts

Set mount host paths to enable bind mounts:
- `dev_data_mount_host_path=` -> `/data`
- `deploy_data_mount_host_path=` -> `/data`

If host path is empty, no data bind mount is created.
